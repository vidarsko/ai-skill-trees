# AI Skill Trees

Teacher-authored prerequisite graphs for school subjects, paired with instructions that turn any
AI chat into a practice tutor, a test generator, a lesson planner and a motivation coach.

The graph is the interface, not the engine: students see the whole structure and choose where to
start. Nothing here calls a language model — the tool composes a teacher-written instruction that
the student pastes into a chat of their choosing.

Website: https://aiskilltrees.com

## Status

Early. The engine and the subject data currently live in a private site repository and are being
extracted here.
